## Vue d'Ensemble du Cours

Ce cours couvre les technologies fondamentales du développement web moderne, structuré en 5 modules principaux:

### Module 1: HTML5 & CSS3 Fondamentaux (Pages 2-35)
- Structure sémantique HTML5
- Mise en forme CSS3 avancée
- Tableaux et formulaires
- Iframes et médias intégrés

### Module 2: Animations CSS3 (Pages 28-35)
- Transitions CSS
- Transformations 2D/3D
- Keyframes et animations
- Timing functions

### Module 3: JavaScript (Pages 36-84)
- Syntaxe de base et variables
- Opérateurs et structures de contrôle
- DOM manipulation
- Événements et interactions

### Module 4: Base de Données (Pages 85-136)
- Modélisation conceptuelle (MCD)
- SQL: DDL, DML, DQL
- Requêtes avancées (JOIN, GROUP BY)
- Contraintes d'intégrité

### Module 5: PHP (Pages 137-167)
- Syntaxe PHP et variables
- Structures conditionnelles et boucles
- Tableaux et fonctions
- Connexion MySQL avec PDO

## Points Forts pour le BAC

1. **HTML5:** Balises sémantiques (`header`, `nav`, `section`, `article`, `aside`, `footer`)
2. **CSS3:** Flexbox, Grid, animations @keyframes
3. **JavaScript:** Manipulation DOM, événements, validation formulaires
4. **SQL:** Requêtes SELECT avec JOIN, GROUP BY, fonctions d'agrégation
5. **PHP:** Sessions, cookies, connexion base de données sécurisée
